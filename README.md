# Foshol Doctor — web

The Angular frontend for Foshol Doctor: AI-triaged crop-disease diagnosis from photographs and
Bangla speech, where **every case is approved by a human field officer before any advice reaches
the farmer**. One application serves all three actors — farmer, field officer, admin.

Built to `docs/requirements/70-frontend.ears.md` in the `foshol-doctor` backend repo. The AI is a
triage accelerator; the human approval gate is the product, and this UI exists to make that gate
and the two-threshold routing *visible*.

## Running it

```bash
./start-ui.sh
```

One command, handles everything: installs or refreshes dependencies only if needed, checks every
dependency is still pinned exactly, generates the API client if it's missing, merges the i18n
catalogues, warns (without blocking) if the backend isn't reachable yet, then serves on
**http://localhost:4200** — the origin the backend's CORS allow-list expects. There is no dev
proxy, deliberately — a proxy would hide a CORS problem until demo day.

`./start-ui.sh --skip-install` skips the dependency check on repeat runs. `PORT=4300
./start-ui.sh` serves on a different port.

Equivalent by hand: `npm install && npm start`.

The backend runs separately:

```bash
cd ../foshol-doctor && ./tools/start-stack.sh
```

> **Read `BACKEND-BLOCKERS.md` first.** At the time of writing the backend does not start from a
> clean build (a Spring bean cycle introduced with the CQRS bus), and `/admin/stats` returns 500
> once any rate is non-null. Both are small fixes in backend modules, diagnosed in that file.

Demo credentials: farmer `+8801711111111` / OTP `123456` · officer `officer` / `password` ·
admin `admin` / `password`. The OTP endpoint is genuinely rate-limited to **3 requests per
10 minutes**, so a scripted loop will lock the farmer out.

## Verifying it

```bash
npm run verify      # i18n parity · exact pins · architecture lint · WCAG AA contrast · tsc strict + strictTemplates
npm run verify:all  # the above, plus regenerate-and-diff the API client, a production build, and 491 tests
```

These are not decoration. Requirements that are usually only promised are enforced as build gates,
and each caught a real defect on its first run:

| Script | Enforces | Caught |
|---|---|---|
| `check:contrast` | `WEB-UX-043` | a 4.32:1 token that needed 4.5:1 |
| `check:arch` | `WEB-SEC-005`, `WEB-API-001`, `WEB-NFR-002/004` | an `innerHTML` in fresh code |
| `check:pins` | `WEB-NFR-005` | the caret ranges `ng new` writes |
| `check-i18n` | `WEB-UX-017` | catalogue drift across ten contributors |

## How it is built

Angular **22.1.5**, pinned exactly, **zoneless**, standalone components, **signals only** — no
NgRx, no `BehaviorSubject` acting as state, RxJS only where an Angular API demands it. Tailwind
CSS 4 with a CSS-first theme, ngx-translate for the runtime BN/EN toggle, and an HTTP client
generated by `ng-openapi-gen` from the frozen OpenAPI contract.

**Zero runtime dependencies beyond those three.** No icon pack, no motion library, no charting
library, no date library. Every pictogram is hand-authored inline SVG and the confidence bars are
CSS — which is what `WEB-NFR-007` asks for, and what keeps the bundle at ~113 kB transferred.

```
src/app/
  core/       config · http interceptors · auth · i18n · sse · stores · media · time · util
  shared/     ui primitives · pipes · directives
  features/   auth · farmer · officer · admin
  generated/  ng-openapi-gen output — regenerated, never hand-edited
```

### Before you change something

- **`core/config/app-config.ts` holds every constant.** No numeric literal belongs in a component
  or service (`WEB-NFR-009`); each mirrored value names the server property it mirrors.
- **Strings live in `src/i18n/<namespace>.i18n.json` fragments**, each key carrying *both*
  languages. `npm run i18n:build` merges them into `public/i18n/`. That shape makes an unpaired
  key structurally impossible rather than merely tested.
- **Agronomic content is never authored here.** Disease names, remedy steps, dosages and
  pre-harvest intervals render exactly as the server returns them, and are never translated
  (`COMMON-CON-003`). A wrong dosage is not a bug, it is harm.
- **The confidence bar is protected.** Both threshold lines render on every bar at every
  confidence, positioned from `analysis.thresholds` — never from local config.
- **Queue order is the server's.** `QueueStore` exposes no comparator at all, so
  least-confident-first cannot be destroyed by a later edit.
- **The JWT lives in memory only** — a refresh is a new login, by design (`WEB-SEC-001`).
  `localStorage` holds the language preference and a draft crop id and note, nothing else.
